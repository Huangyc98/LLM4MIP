Simplified experiment setup

The same four gates for every claim

Freeze

Record the untouched model, baseline, objective convention, and acceptance tolerance.

Understand

Profile the matrix and formulate at least two falsifiable structural hypotheses.

Test

Run bounded primal, dual, reduction, enumeration, or certificate experiments.

Verify

Map survivors back to the original MPS and report only the evidence grade earned.

Bundle policy: each archive retains reports, scripts, artifacts, public solutions, derived proof models, logs, runs, and proof traces present in the instance directory. Only official raw input/*.mps* files are omitted; their sizes and SHA-256 hashes appear in the package manifest. Externally retained files cannot be embedded, and their source notes remain visible. The source license is included. The historical rmine14 calibration is not one of the 112.
