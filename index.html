How much can LLMs help solve MIPs?

LLM-assisted solver workflows resolved 30 of 112 open MIPLIB instances

Mixed-integer programming (MIP) is a core modeling tool for planning, scheduling, logistics, energy systems, and many real-world applications. However, MIPs are notoriously hard to solve even with state-of-the-art optimization solvers.

Large language models (LLMs) have recently shown promise in advancing open problems in mathematics. An unresolved MIP instance can likewise be viewed as an "open problem": its variables, constraints, objective, and data define a concrete numerical open problem.

Central question Can LLMs make real-world MIP solving more effective, especially by accelerating established solver-based workflows?

Starting from a benchmark of 217 open MIPLIB instances, we studied 112 using LLM-assisted solver workflows. Across these experiments, LLM reasoning complemented numerical optimization solvers by broadening the search for exploitable structure, primal heuristics, and dual certificates, while solvers and independent checks supplied numerical bounds and result verification.

Conclusion LLM + optimization solver is a powerful workflow for real MIP solving.

Based on the instance-level analyses, we created reusable skills for LLM-assisted solver workflows. They guide systematic analysis of instance structure and boosts solver performance in a separate 20-instance test set.
