Skill focus

How the skill helps LLM-assisted MIP solving

  • Find useful structure: identify exploitable patterns, primal heuristics, and dual certificates instead of relying only on generic solver tuning.
  • Run targeted experiments: turn structural observations into focused tests with an optimization solver.
  • Verify every result: check candidate solutions and bounds against the original model, using independent verification to determine what can be claimed.

Comparison design

What was compared

Skill-guided arm

Run controlled_miplib20_20260911_1451: Codex gpt-5.6-sol at ultra reasoning, Gurobi 13.0.1, eight solver threads per instance, and a 32 GiB soft cap. Two disclosed cases used Windows/Gurobi 13.0.2.

Comparison arm

An archived comparison workflow on the same 20 minimization instances that did not use this specific skill. It still used computational tools and problem-specific methods; it is not a “solver-only” control.

Models and public baselines were frozen on 11 September 2026. The five batches ran at most four instances in parallel, with batch barriers and no transfer of unused time. Batch 1 allowed 40–120 active minutes per instance; batches 2–5 allowed 90–150. The skill run accumulated 1,729.5301 active minutes and 1,010.2245 overlapping solver minutes.

Design limit: this is a paired retrospective reconstruction, not a randomized, blinded, equal-resource A/B experiment. Machines, budgets, solver states, starts, baselines, tolerances, stopping decisions, and research order may differ. The page reports descriptive outcome and workflow differences, not a net causal effect.
